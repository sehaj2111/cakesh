# cakeSh — cake a bite Website

Static 3D-animated website for **cakeSh (cake a bite)** in Kharar, Mohali (`@cakeabiteee`).

## Deploy to Vercel via GitHub
1. Upload `index.html`, `vercel.json`, and the `assets/` folder to the root of a GitHub repository.
2. Go to [vercel.com](https://vercel.com), click **Add New → Project**, and import your GitHub repository.
3. Keep **Framework Preset** as **Other**, leave **Build Command** empty, and leave **Output Directory** empty.
4. Click **Deploy**.
